# channel — automated Hindi buying-guide videos

A pipeline that turns structured product data into faceless YouTube buying
guides for Indian smartphone shoppers ("best phone under ₹20,000", head-to-heads,
launch explainers, deal Shorts, monthly refreshes). The voice is TTS only and
every visual is rendered by code. Every number traces back to a sourced data
file.

See [docs/PLAN.md](docs/PLAN.md) for the full plan, assumptions and open questions.

## Quick start (Docker only)
Everything runs in Docker: Python, uv, ffmpeg, libraqm (Hindi text shaping) and
Noto Sans Devanagari. The host needs only Docker Desktop.

```bash
cp .env.example .env    # secrets go here; never commit .env (optional for Phase 1)
make build              # build the yt-channel:dev image
make check              # ruff + pytest, in the container
make demo               # validate data, rank every price band, one head-to-head
make shell              # bash inside the container
```

The repo is bind-mounted at `/app`, so code edits are picked up without a
rebuild. The virtualenv lives at `/opt/venv` inside the image. Rebuild
(`make build`) only after changing dependencies; run `make lock` to update
`uv.lock` inside the container. `make demo` writes JSON to `out/demo/phase1/`
on the host.

## CLI (inside the container)
```bash
docker compose run --rm app channel validate
docker compose run --rm app channel score tarang-t9             # full score breakdown
docker compose run --rm app channel rank --band 20000           # best under ₹20,000 (add --json)
docker compose run --rm app channel compare tarang-t9 ostra-o2  # head-to-head

# Scripts (Phase 2). Default writer is Claude; needs ANTHROPIC_API_KEY in .env.
docker compose run --rm app channel script best_under --band 20000
docker compose run --rm app channel script head_to_head --a tarang-t9 --b ostra-o2
docker compose run --rm app channel script launch_explainer --product zentra-z8-pro
docker compose run --rm app channel script deal_short --product ostra-o2 --writer template
docker compose run --rm app channel script monthly_refresh --band 30000 --lang en
docker compose run --rm app channel factcheck out/videos/<video_id>/script.json  # exit 1 = blocked
docker compose run --rm app channel costs                     # this month's API spend

# Voice + render (Phase 3). Only fact-checked scripts can be rendered.
docker compose run --rm app channel render best_under-20000-2026-11-20-hi --tts espeak
docker compose run --rm app channel proofs                    # Devanagari proofs + format contact sheet
```

The template writer (`--writer template`) supports `best_under` and `deal_short`
offline; the other three formats need Claude. See [docs/FACTCHECK.md](docs/FACTCHECK.md)
for the claim format and every rule the fact-checker enforces.

## Data rules
- Every spec, launch fact and price has `source_url` and a timezone-aware
  `fetched_at`; loading fails without them.
- Spec keys and types are fixed in `src/channel/data/specs.py`. Typos and
  wrong types fail at load time.
- **SAMPLE data**: records with `sample: true` must point at `example.com`,
  and real records must not. A dataset can't mix the two. Sample product names
  are shown as `[SAMPLE] …`, and the CLI prints a SAMPLE banner.
- Prices enter only through a `PriceProvider`. `ManualCSVProvider` works;
  `AmazonAssociatesProvider` and `FlipkartAffiliateProvider` are stubs. No
  scraping.
- The current price is the lowest of each retailer's latest observation on or
  before the as-of date, and no older than `max_price_age_days` (7). Stale
  products are excluded from lists, with the reason given.

## Scripts and fact-check (summary)
- Every number in narration must be a claim `{text, ref, value}` that cites the fact
  table. The checker rebuilds that table from the data itself and fails on any
  mismatch, unclaimed number, hands-on phrase, or missing or edited disclosure.
- A failing script is saved with its report but blocked:
  `require_passed()` refuses render and upload unless the report passes for that exact
  script and the current data.
- Claude responses are cached in `cache/channel.sqlite`; every call is logged with its
  cost in INR, and paid calls stop at ₹3,000/month or ₹150/video.

## Voice and render (summary)
- TTS is behind `TTSProvider`: Google Cloud (`hi-IN-Neural2-B`) is primary, espeak-ng is the
  offline fallback. Audio is cached per sentence; characters and cost go to the same ledger.
- Frames are drawn with Pillow (raqm for Devanagari) and matplotlib; five formats have
  distinct themes. Every frame has "price as of <date>"; SAMPLE data is watermarked on every frame.
- `assets/music/` files are mixed under the voice and ducked while it speaks.
- Full detail: [docs/RENDER.md](docs/RENDER.md).

## Language
`CHANNEL_LANG=hi|en` (default `hi` from settings). `LANG=hi|en` also works, but
because shells set `LANG=en_US.UTF-8`, any other `LANG` value is ignored.
